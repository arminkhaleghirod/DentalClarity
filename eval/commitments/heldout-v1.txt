Scheme
- Each case has its own salt: 32 random bytes, written as 64 lowercase hex characters.
- Per-case hash = sha256( salt_hex || file_bytes ), where salt_hex is the 64-character
  ASCII hex string (no newline) and file_bytes are the exact bytes of the case file
  (UTF-8, LF line endings, as kept by the repo's .gitattributes).
- Root hash = sha256 of the 36 per-case hashes, as lowercase hex, sorted ascending,
  concatenated with no separators and no trailing newline.

How to verify after publication (POSIX shell with sha256sum; on macOS use "shasum -a 256")
Run from the directory that holds the published cases/ folder and salts.txt:

  while read id salt; do
    f=$(ls cases/*/"$id".toml)
    h=$( { printf '%s' "$salt"; cat "$f"; } | sha256sum | cut -d' ' -f1 )
    echo "$id $f $h"
  done < salts.txt > recomputed.txt

  # 1. Every line must match the per-case table above.
  # 2. The root must match the root hash above:
  cut -d' ' -f3 recomputed.txt | sort | tr -d '\n' | sha256sum

A case file whose line endings were converted (for example CRLF on checkout) will not
match; compare the bytes of the published archive, or check out with LF endings.
