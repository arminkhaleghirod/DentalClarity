# DentalClarity brand

The mark is a molar whose left root sweeps out into the tail of a speech bubble, with three dots in the crown. It reads as a tooth that is talking: the dentist's plan, explained to the patient in their own language. The shape is drawn as a single filled path with the dots cut out, so it stays legible from a 16 px favicon up to a 512 px app icon.

Colors: the mark and the word "clarity" use dental blue #2A7DD1, and the word "dental" uses navy #1B3A5C. On dark backgrounds use `logo-on-dark.svg`, which switches to white and a lighter blue (#5AA2EA) so the mark keeps its contrast. The wordmark is set in Figtree (weight 600) with a system sans fallback.

Files:

- `logo.svg`: mark and wordmark, for light backgrounds
- `logo-on-dark.svg`: the same for dark backgrounds
- `logo-mark.svg`: the mark alone, square
- `logo-mono.svg`: one color, follows `currentColor`
- `favicon.svg`: the mark, copied into the web app build
- `logo-mark-512.png`, `logo-mark-192.png`, `logo-mark-32.png`: raster exports with a transparent background
- `concepts/`: the three directions explored before choosing this one

The logo is original work made for this project and is released under the project's Apache-2.0 license.
