# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability"). Do not open a public issue.

Include what you found, how to reproduce it, and which version or commit you tested. You should get a reply within a week.

## Scope

DentalClarity is a prototype and is not approved for real patient data. Reports about the public demo, the server, the web app and the provider adapters are all welcome. Never test with real patient information.

The threat model and security design are in [docs/SECURITY.md](docs/SECURITY.md).
